# Third-party font notices

Font binaries are unmodified Google Fonts web subsets, obtained from fonts.googleapis.com / fonts.gstatic.com. Individual upstream licenses are copied from the google/fonts repository and are retained under fonts/licenses/. SOURCES.json records each file, family, CSS source, binary source and upstream license URL. The 160 selected families are under the SIL Open Font License 1.1; actual family copyrights/reserved-name provisions remain in the license files.

The font binaries are not MIT-licensed. Preserve their license and copyright notices; do not sell the fonts by themselves or misrepresent authorship. Subset/weight and language coverage vary; the catalog describes what is actually bundled. No paid commercial typefaces are included. Original logo SVGs, component markup, catalog recipes and motion CSS were authored for this pack.
